# ColorTile

ColorTile is a fast-paced puzzle game where players swap colored tiles to restore a smooth gradient across the board before time runs out.

Each round starts with a scrambled grid generated from four corner colors. Your objective is to strategically swap tiles until the entire board blends seamlessly from corner to corner. The faster you solve the puzzle and the fewer moves you use, the higher your score.

## Features

* 🎨 Procedurally generated color gradient puzzles
* 🔄 Tile swapping gameplay
* ⏱️ Timed puzzle challenges
* 📊 Move counter and completion tracking
* 🏆 Global leaderboards
* 📅 Daily puzzles
* 📱 Mobile-friendly responsive design
* 🚀 Built with Next.js, TypeScript, and Tailwind CSS

## Gameplay

1. Start with a scrambled color grid.
2. Tap two tiles to swap their positions.
3. Restore the smooth gradient between all four corner colors.
4. Aim for the fastest time and fewest moves possible.
